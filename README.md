# MinimalTask 📝

A minimal Todo List application built with HTML, CSS, and Vanilla JavaScript.

---

## 🚀 Project Overview

MinimalTask is a clean and lightweight Todo application with core functionality:

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Minimal and distraction-free UI

---

## 🧠 Purpose of This Project

This project was created primarily to experiment with AI-assisted development workflows.

The goal was not to learn JavaScript fundamentals, but to:

- Test how efficiently AI can generate structured frontend code
- Evaluate code quality and logic produced by AI
- Iterate quickly using prompt-driven development
- Optimize development speed while maintaining full understanding of the implementation

Since I already have a solid understanding of JavaScript and DOM manipulation, I focused on reviewing, validating, and refining the generated code rather than writing everything manually.

---

## ⚙️ Development Approach

1. Defined the desired functionality and UI behavior.
2. Used AI to generate the base implementation.
3. Reviewed the logic and structure.
4. Refined and adjusted parts where necessary.
5. Tested edge cases and improved clarity.

This project serves as an experiment in modern AI-assisted development rather than a fundamentals exercise.

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (DOM manipulation)
